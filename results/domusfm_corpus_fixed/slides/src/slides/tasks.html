Introduction · training and testing

Pretraining, then two tests

Pretraining: a matching game

Two masked copies of the same 30-event window must find each other among 128 candidates (InfoNCE loss). Phase 1 hides attributes; phase 2 hides whole events.

Test 1 · Activity (ADL)

Name the activity at the last event of a window, such as cooking or sleeping. Scored with weighted F1.

Test 2 · Next-30

Predict which event types occur in the next 30 events, and how often. Scored with multiset F1.

Every score is compared with the same model trained from random weights ("no pretraining"). Pretraining is only worth having if it beats that. F1 runs from 0 to 1; higher is better.
