Introduction · the model

How the model reads a home

1

One sensor event

Item, type and room as text, embedded by a frozen MiniLM. Status ON or OFF. Time: day, hour, second.

2

Attribute attention

One transformer layer fuses the 5 attributes into a single event vector.

3

Context encoder

A 12-layer transformer, 12 heads, width 384, reads a window of 30 events. No positional encoding.

4

Task heads

ADL: the activity at the last event. Next-30: which events come next, and how many.

28.6M parameters in total. The paper reports 36.1M; the gap is unexplained, since layer widths such as the feed-forward size (2048 here) are not reported.
