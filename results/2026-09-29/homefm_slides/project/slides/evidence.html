Loss collapse: 2.35 → about 0.0005 within 5,000 of 40,000 steps. Next-30 prediction: no difference either way.

Patching the game works for activities: with six fixes, pretraining wins 26 of 28 settings (activity F1 at 5 % labels: 0.517 vs 0.441).

But the fixed game still trains none of: timing, surprise, per-minute meaning, robustness to a missing device, language.

So HomeFM replaces the game instead of patching it. Masking is not thrown away: game 2 hides big structured chunks and must recover them; our DomusFM fix's fill-in-the-blanks loss points the same way.
