Pretraining · DomusFM's game

How DomusFM pretrains: hide a little, then find your own window

Phase 1 · attribute masking

For about 15 % of events, hide one attribute:

18:29 fridge door · contact · kitchen · OPEN
18:29 fridge door · contact · kitchen · ???

Phase 2 · event masking

For about 15 % of events, hide all attributes; event layers frozen:

18:30 stove · power · kitchen · ON
??? · ??? · ??? · ???

Original window → model → average → vector A

Among 64–128 windows in the batch, each A must pick out its own masked copy B (InfoNCE)

Masked window → model → average → vector B

The key weakness: the model is never asked what was hidden. Masking is only damage; the task is to recognise the window despite it. Knowing that “the stove usually follows the fridge” gives no advantage.

Both phases use the same contrastive game. Only the kind of damage differs.
