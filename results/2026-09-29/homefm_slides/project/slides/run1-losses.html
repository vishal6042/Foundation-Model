Matching: 4.85 means pure guessing, 0 means never wrong. Run 1 hit 0.001 by step 1,000: the game was too easy to teach anything. With the fixes it stays at 0.7–0.9: hard enough to keep learning. The jump at 20k is the switch to the harder phase-2 game.

Fill in the blanks: lower means better guesses. It falls from 4.0 to about 0.2 when single facts are hidden, and sits at 0.5–0.7 when whole events are hidden (harder).

Matching loss = the contrastive (InfoNCE) loss; fill-in-the-blanks = the masked-attribute loss added by fix 5. Run 1: results/domusfm_corpus (one pretraining, logged every 1,000 steps). Run 3: mean of its five pretrained models, which are nearly identical; run 2 looks the same (0.70–0.82). Chance = ln 128 = 4.85 for both. Phase 1 hides single facts (attribute masking); phase 2 hides whole events.
